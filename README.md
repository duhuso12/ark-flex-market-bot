ARK FLEX MARKET Discord Bot

Setup:
1. npm install
2. Copy .env.example to .env and fill DISCORD_TOKEN, GUILD_ID and TICKET_CHANNEL_ID.
3. npm start

Local artwork:
- assets/soakers/ contains the Flex Market soaker images.
- assets/pvp/ contains the finished neon-blue Flex Market PvP images.
- PvP Karkinos currently has no finished neon-blue local artwork in the supplied files, so the bot keeps its existing dossier fallback for that one entry.
